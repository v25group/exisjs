# create-exis

The short name for [create-exisjs](https://www.npmjs.com/package/create-exisjs): `npm create exis@latest` runs the same scaffolding tool as `npm create exisjs@latest`.

```bash
npm create exis@latest my-app
```

Documentation: [github.com/v25group/exisjs](https://github.com/v25group/exisjs)
