# ExisJS Release v0.7.0

**Release Date:** 2026-09-06  
**Commit:** `6a1b8ad`  
**Type:** Major Architectural Evolution  
**Affected Packages:** All (`exisjs`, `@exisjs/rs`, `create-exisjs`, `@exisjs/telemetry`, `@exisjs/fetch`)

---

## Highlights

- **Core Decoupling**: Extracted monolithic submodules out of core into standalone packages, leaving an ultra-minimal, high-performance zero-allocation runtime.
- **Hierarchical Boundaries**: Introduced the modern `boundary.ts` pipeline with auto-detected middleware wrapping and `defineBoundary()` configuration.
- **Native Schema Engine**: Migrated schema validation to the native Rust-powered `tex` builder with static TypeScript type inference (`ResolveSchema`).
- **CLI Scaffolding Package**: Released `create-exisjs` enabling zero-install project creation via `npm create exisjs@latest`.
- **Cross-Platform Native Binaries**: Established cross-platform N-API build and publish pipeline for `@exisjs/rs` supporting Linux (musl & gnu), macOS (ARM64 & x64), and Windows (x64 & ARM64).

---

## Detailed Changes

### Added

#### The Modern Boundary Pipeline
```typescript
// src/http/admin/boundary.ts
import { defineBoundary } from 'exisjs/router'
import { authMiddleware } from '@/middleware/auth'

export const config = defineBoundary({
  middleware: [authMiddleware],
  exclude: ['/admin/login']
})
```

#### Native Schema Validation with Type Inference
```typescript
import { tex } from 'exisjs/validator'
import type { ResolveSchema } from 'exisjs/validator'

export const CreateUserSchema = tex.object({
  name: tex.string({ min: 3 }),
  email: tex.email(),
  role: tex.enum(['admin', 'member'])
})

export type CreateUserDto = ResolveSchema<typeof CreateUserSchema>
```
