# ExisJS Release v0.7.1

**Release Date:** 2026-09-06  
**Commit:** `7ac061e`  
**Type:** Feature & Logging Overhaul  
**Affected Packages:** `exisjs`, `create-exisjs`

---

## Highlights

- **OOP Parity Decorators**: Added `@Module`, `@Inject`, `@Optional`, and transient DI scopes.
- **Metadata Reflector**: Introduced `@SetMetadata` and the `Reflector` utility (`get`, `getAllAndOverride`, `getAllAndMerge`).
- **Unified `@Use(...)` Decorator**: Single decorator handles middlewares, guards (`canActivate`), interceptors (`intercept`), and exception filters (`catch`).
- **Logging Overhaul**: Established `exisjs/logger` as the canonical export point and replaced raw `console.*` calls with structured Pino logging.

---

## Detailed Changes

### Added

#### Dependency Injection Decorators
```typescript
import { Injectable, Inject, Optional } from 'exisjs/di'

@Injectable()
export class NotificationService {
  constructor(
    @Inject('CONFIG_TOKEN') private config: any,
    @Optional() @Inject('ANALYTICS') private analytics?: any
  ) {}
}
```

#### Unified Decorator Execution
```typescript
@Use(authGuard, auditInterceptor)
@Controller('/admin')
export default class AdminController {}
```

---

### Changed

- **Rate Limiting Engine**: Cleaned up abandoned Redis options in core rate limiting in favor of `@exisjs/cache`.
