# ExisJS Release v0.7.8

**Release Date:** 2026-09-22  
**Type:** Patch & Export Fixes  
**Affected Packages:** `exisjs`, `create-exisjs`

---

## Highlights

- **Package Subpath Export (`exisjs/swagger`)**: Added `./swagger` to `packages/exisjs/package.json` subpath exports mapping, enabling clean, dedicated imports from `exisjs/swagger` (`swagger`, `docs`, `defineSwagger`, `generateOpenApiSpec`, `renderDocumentationHtml`, and all OpenAPI decorators).
- **Documentation Accuracy & File Conventions**:
  - Aligned all Swagger guide examples in `docs/content/swagger.mdx` and `docs/reference/swagger.mdx` with canonical ExisJS folder routing (`src/http/users/route.ts`, `src/http/products/route.ts`).
  - Standardized OOP class controller examples with `export default class ...` and `@Controller()`.
  - Documented advanced configuration options in `exis.config.ts` (`transformSpec`, `servers`, `securitySchemes`, `customCss`) and optional server boot hooks in `src/http/server.ts`.
- **Dependency Alignment**: Updated `create-exisjs` template generator dependency to `exisjs: '^0.7.8'`.

---

## Key Improvements

### 1. `exisjs/swagger` Subpath Resolution
Consumers and external tooling can now reliably import Swagger utilities:
```typescript
import { generateOpenApiSpec, renderDocumentationHtml, swagger } from 'exisjs/swagger'
```

### 2. Documentation Parity
All Swagger documentation pages strictly reflect ExisJS architecture without placeholder file paths or conflicting setup instructions.
