# ExisJS Release v0.7.4

**Release Date:** 2026-09-11  
**Commit:** `ced6985`  
**Type:** Feature & Validation Enhancements  
**Affected Packages:** `exisjs`, `@exisjs/rs`, `create-exisjs`

---

## Highlights

- **Nested Validation & Coercion**: Rust-powered `tex` validator supports nested `array<object<...>>` schemas, single-object coercion, stringified JSON arrays, and `.nullish()`.
- **Automatic Empty String `""` Normalization**: Automatically converts empty strings from forms/queries to `undefined` or `null` before running type checks.
- **Tabular Terminal Diagnostics**: Dev-mode validation rejections display an immediate Unicode box-drawing table with field, received value, and expected schema constraint.
- **Declarative Multipart Uploads**: Upload files directly via route definitions (`upload: { field, maxSize, destination }`) or OOP decorators (`@UseUpload`, `@Upload`).
- **Route-Level Timeout Overrides**: `timeoutMs: 120000` and `@Timeout()` decorator to dynamically update or cancel global timeouts.
- **Database Lifecycle Utilities**: Connection manager and transaction utilities under `exisjs/database`.

## Detailed Changes

### Added

#### Tabular Validation Diagnostics
When validation fails in development mode:
```text
[VALIDATION FAILED] POST /visits (part: body)
┌─────────────┬───────────────────────────┬──────────────────┐
│ Field       │ Received                  │ Expected         │
├─────────────┼───────────────────────────┼──────────────────┤
│ phone       │ "123"                     │ min: 7, max: 20  │
│ idProofs    │ "[object Object]"         │ Array of IDProof │
└─────────────┴───────────────────────────┴──────────────────┘
```

#### Declarative File Uploads
```typescript
import { controller, route } from 'exisjs/router'

export default controller({
  uploadAvatar: route.post('/avatar', {
    upload: {
      field: 'avatar',
      maxSize: '5MB',
      destination: './uploads'
    },
    handle({ file, body }) {
      return { uploaded: file.filename }
    }
  })
})
```

#### Dynamic Route Timeouts
```typescript
export default controller({
  exportReport: route.post('/export', {
    timeoutMs: 180000, // 3 minutes override
    async handle({ res }) {
      const data = await generateHeavyReport()
      res.json(data)
    }
  })
})
```

### Fixed

- **Plain Object Array Types**: Fixed TypeScript type inference for plain object schemas inside `tex.array({ ... })` resolving to `never`.
- **Stream/Upload Timeout Protection**: Allowed explicit timeout extensions via `req.setTimeout()` to prevent premature socket termination on slow client networks.
