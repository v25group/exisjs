# ExisJS Release v0.7.3

**Release Date:** 2026-09-09  
**Commit:** `15fcb04`  
**Type:** Feature & Performance  
**Affected Packages:** `exisjs`, `@exisjs/rs`, `create-exisjs`

---

## Highlights

- **Rust Native Compression**: High-speed off-heap compression (`brotli`, `gzip`, `deflate`, `compress_best`) using `brotli` v7 and `flate2` in `@exisjs/rs`.
- **Pre-Compressed Static Serving**: Automatic `.br` and `.gz` static file serving with strong ETag generation and 304 conditional handling.
- **Server-Sent Events (SSE)**: First-class SSE subsystem (`SSEStream`, `formatSSEEvent`) with keep-alive heartbeats and client disconnect callbacks via `res.sse()`.
- **CLI Commands**:
  - `exis routes`: Inspect mounted routes, HTTP methods, and schemas directly from the terminal.
  - `exis doctor`: Environment and diagnostics system check.
  - `exis g --named`: Slice-based generation (`user.route.ts`, `user.schema.ts`, `user.service.ts`).
- **Example App**: Created `examples/04-realtime-sse` featuring live browser SSE streaming.

## Detailed Changes

### Added

#### Real-Time SSE
```typescript
import { controller, route } from 'exisjs/router'

export default controller({
  feed: route.get('/events', {
    handle(req, res) {
      const sse = res.sse()
      
      const interval = setInterval(() => {
        sse.send({ timestamp: Date.now() }, 'tick')
      }, 1000)

      sse.onClose(() => {
        clearInterval(interval)
      })
    }
  })
})
```

#### CLI Route Inspection
```bash
exis routes
# Prints:
# Method   Path           File                         Schemas
# GET      /api/users     src/http/users/route.ts      query
# POST     /api/users     src/http/users/route.ts      body, query
```
