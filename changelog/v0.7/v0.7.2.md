# ExisJS Release v0.7.2

**Release Date:** 2026-09-06  
**Commit:** `0c42ca7`  
**Type:** Bug Fixes & Router DX  
**Affected Packages:** `exisjs`, `create-exisjs`

---

## Highlights

- **TypeScript Parameter Inference**: Automatic route param type extraction via `ExtractRouteParams<TPath>` on `route.*` and `createRouter()`.
- **Runtime Path Aliases**: Native `@/*` resolution in build command, start server, and route auto-mounting.
- **Deprecation Warnings**: Automatic warning when legacy `gateway.ts` / `gateway.js` files are detected.
- **Plural Middleware Support**: Supports both `middlewares: [...]` and `middleware: [...]` across controllers and boundaries.

---

## Detailed Changes

### Added

#### Inferred Route Params
```typescript
// params is automatically typed as { id: string, tab: string }
route.get('/users/:id/tabs/:tab', {
  handle({ params }) {
    console.log(params.id, params.tab)
  }
})
```

---

### Fixed

- **ESM Relative Specifiers**: Fixed relative specifier rewriting in `resolve-aliases.ts` to support multi-dot filenames (e.g. `user.model.js`) and directories without stripping or skipping extensions in ESM mode.
