# Server-Sent Events (SSE)

Server-Sent Events (SSE) is a server push technology enabling a client to receive automatic updates from a server via an HTTP connection. Unlike WebSockets, SSE is unidirectional (server-to-client) and works over standard HTTP without requiring complex handshake protocols or specialized load balancer configurations.

SSE is the industry standard for Large Language Model (LLM) streaming (e.g., OpenAI, Anthropic) and real-time dashboard updates. ExisJS provides native SSE support.

---

## 1. Creating an SSE Stream

When you declare a route as an SSE endpoint using `route.sse()` or `@Sse()`, ExisJS automatically configures the correct HTTP headers (`Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`) and provides an `ExisSSE` stream object.

### Functional Paradigm

```typescript filename="src/http/chat/route.ts"
import { controller, route } from 'exisjs/router'
import Groq from 'groq-sdk'

export default controller({
  chat: route.sse('/api/chat', {
    async handle({ stream: sse, req }) {
      const groq = new Groq({ apiKey: process.env.GROQ_API_KEY })
      const message = req.query.message as string
      
      if (!message) {
        sse.send({ error: 'Message is required' }, 'error')
        sse.close()
        return
      }

      try {
        const aiStream = await groq.chat.completions.create({
          messages: [{ role: 'user', content: message }],
          model: 'llama-3.1-8b-instant',
          stream: true,
        })

        // Iterate over the async generator provided by the AI SDK
        for await (const chunk of aiStream) {
          // Prevent writing to a closed socket if the client disconnects early
          if (!sse.connected) break
          
          const content = chunk.choices[0]?.delta?.content || ''
          if (content) {
            sse.send({ text: content }, 'chunk')
          }
        }
        
        sse.send({ text: '' }, 'done')
      } finally {
        // Ensure the connection is always closed when processing completes
        sse.close()
      }
    }
  })
})
```

import { Controller, Sse, Stream, Req } from 'exisjs/decorators'
import type { ExisSSE } from 'exisjs/router'

@Controller()
export default class AIChatController {
  @Sse('/api/chat')

  }
}

## 2. The `ExisSSE` API

The injected `sse` object gives you full control over the streaming connection:

- **`sse.send(data: string | Record<string, any>, eventName?: string)`**: Serializes the data (if it is an object) to JSON and sends it down the wire. You can optionally tag it with a specific `eventName`.
- **`sse.connected`**: A boolean that evaluates to `true` while the connection is alive. You should always check this inside long-running `for await` or `while` loops to prevent throwing "Socket Closed" errors when the client disconnects unexpectedly.
- **`sse.close()`**: Safely closes the stream and terminates the HTTP connection.

```typescript
// Sending a plain text message
sse.send("Processing your request...")

// Sending a JSON object tagged with a specific event type (e.g., 'metrics')
sse.send({ cpu_usage: 95, mem_usage: 60 }, 'metrics')
```

## 3. Client-Side Consumption

To consume the SSE stream from the frontend (e.g., in React, Vue, or Vanilla JS), use the native browser `EventSource` API.

```javascript filename="frontend/app.js"
// Connect to the ExisJS SSE endpoint
const eventSource = new EventSource('/api/chat?message=Hello')

// Listen for the default 'message' event (when no eventName is specified in sse.send)
eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data)
  console.log("Standard message:", data)
}

// Listen for a custom event type, such as 'chunk'
eventSource.addEventListener('chunk', (event) => {
  const data = JSON.parse(event.data)
  // Append the streamed text to the DOM
  document.getElementById('output').textContent += data.text
})

// Listen for the 'done' event to close the connection from the client side
eventSource.addEventListener('done', () => {
  console.log("Stream finished.")
  eventSource.close()
})

// Handle connection errors
eventSource.onerror = (error) => {
  console.error("SSE Connection Error:", error)
  eventSource.close()
}
```
