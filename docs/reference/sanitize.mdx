# `exisjs/sanitize`

The `exisjs/sanitize` module provides pure data sanitization functions for cleaning and normalizing input strings, numbers, dates, arrays, and complex objects before business logic execution. It includes security transforms for XSS escaping, HTML stripping, and basic SQL injection and path traversal probe detection.

---

## Module Exports

```typescript
import { sanitize } from 'exisjs/sanitize'
```

---

## 1. Security Sanitizers

The SQL and path traversal checks reject common probe strings; they complement, and never replace, parameterized queries and resolved-path checks.

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.escapeHtml` | `(val: string) => string` | Escapes `&`, `<`, `>`, `"`, and `'` into HTML entity equivalents. |
| `sanitize.stripHtml` | `(val: string) => string` | Strips all HTML tags and markup characters from the string. |
| `sanitize.preventSql` | `(val: string) => string` | Neutralizes common SQL injection sequences and comment tokens. |
| `sanitize.preventTraversal` | `(val: string) => string` | Strips directory traversal sequences (`../`, `..\\`, null bytes). |
| `sanitize.maskEmail` | `(val: string) => string` | Obfuscates email addresses (e.g., `al***@example.com`). |
| `sanitize.maskString` | `(val: string) => string` | Masks sensitive string segments for logging or auditing. |

---

## 2. Text & String Sanitizers

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.trim` | `(val: string) => string` | Strips leading and trailing whitespace. |
| `sanitize.toLowerCase` | `(val: string) => string` | Converts all characters to lowercase. |
| `sanitize.toUpperCase` | `(val: string) => string` | Converts all characters to uppercase. |
| `sanitize.collapseWhitespace`| `(val: string) => string` | Collapses consecutive whitespace, tabs, and newlines into a single space. |
| `sanitize.normalizeUnicode` | `(val: string) => string` | Normalizes Unicode characters to Canonical Decomposition followed by Canonical Composition (NFC). |
| `sanitize.slugify` | `(val: string) => string` | Converts strings into clean URL-friendly slugs (`"Hello World!"` $\to$ `"hello-world"`). |
| `sanitize.truncate(length)` | `(length: number) => (val: string) => string` | Truncates strings exceeding the specified maximum length. |
| `sanitize.removeNonAlphanumeric` | `(val: string) => string` | Strips all characters except standard ASCII letters and numbers. |
| `sanitize.normalizeLineEndings` | `(val: string) => string` | Converts Windows CRLF (`\r\n`) to POSIX LF (`\n`). |

## 3. Numbers & Dates

### Number Transforms

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.round` | `(val: number) => number` | Rounds a float to the nearest integer. |
| `sanitize.clamp(min, max)` | `(min: number, max: number) => (val: number) => number` | Constrains numeric input to fall within `[min, max]`. |
| `sanitize.defaultIfNaN(fallback)` | `(fallback: number) => (val: number) => number` | Returns the fallback number if input evaluates to `NaN`. |

### Date Transforms

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.normalizeToIsoString` | `(val: Date) => string` | Formats a Date object into an ISO 8601 string representation. |
| `sanitize.stripTime` | `(val: Date) => Date` | Resets hours, minutes, seconds, and milliseconds to `00:00:00.000`. |

---

## 4. Arrays & Complex Objects

### Array Transforms

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.dedupe` | `<T>(val: T[]) => T[]` | Removes duplicate values preserving first-seen ordering. |
| `sanitize.compact` | `<T>(val: T[]) => T[]` | Removes `null`, `undefined`, and empty strings (`""`). |
| `sanitize.trimElements` | `(val: string[]) => string[]` | Trims whitespace from all string elements in an array. |
| `sanitize.limitLength(n)` | `<T>(length: number) => (val: T[]) => T[]` | Slices an array to at most `length` elements. |

### Object Transforms

| Function | Signature | Description |
| :--- | :--- | :--- |
| `sanitize.stripUnknownKeys(keys)` | `<T>(allowedKeys: (keyof T)[]) => (val: T) => T` | Strips unlisted properties from an object. |
| `sanitize.deepTrimStringValues` | `<T>(val: T) => T` | Recursively walks an object graph and trims all nested string properties. |
| `sanitize.omit(keys)` | `<T, K extends keyof T>(keys: K[]) => (val: T) => Omit<T, K>` | Removes specified keys from an object. |
| `sanitize.pick(keys)` | `<T, K extends keyof T>(keys: K[]) => (val: T) => Pick<T, K>` | Returns an object containing only the specified keys. |

## 5. Integration with TexEngine Validation

Sanitizers integrate with `tex` validator chains using the `.sanitize()` modifier. Sanitization occurs **before** rule validation checks:

```typescript filename="src/http/articles/schema.ts"
import { tex } from 'exisjs/validator'
import { sanitize } from 'exisjs/sanitize'

export const CreateArticleSchema = tex.object({
  title: tex
    .string({ min: 5, max: 120 })
    .sanitize(sanitize.trim, sanitize.collapseWhitespace),

  slug: tex
    .string()
    .sanitize(sanitize.slugify),

  content: tex
    .string()
    .sanitize(sanitize.stripHtml),

  tags: tex
    .array(tex.string())
    .sanitize(sanitize.dedupe, sanitize.compact),
})
```

## 6. Standalone Usage Example

```typescript filename="src/services/import.service.ts"
import { sanitize } from 'exisjs/sanitize'

export function processUserInput(rawContent: string): string {
  const step1 = sanitize.stripHtml(rawContent)
  const step2 = sanitize.collapseWhitespace(step1)
  const clean = sanitize.trim(step2)
  return clean
}
```
